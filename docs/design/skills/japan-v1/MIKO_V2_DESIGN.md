# Miko v2 — purification into blessing (proposal 2026-10-11, awaiting user approval)

Japan's second class (RANGED main healer). Applies the audit rules: one signature mechanic, no bow (Norway owns the
hunter bow, USA the sniper bow), no deity names in skill names, no duplicate cheat-death. Numbers provisional.

## Signature mechanic: Harae — impurity becomes blessing

In Shinto practice purification (*harae*) removes impurity (*kegare*). Here, **every debuff the Miko cleanses turns
into a matching blessing** on that ally for a few seconds:

| Cleansed | Becomes |
|---|---|
| Poison / Bleed / DOT | Regen |
| Curse / DEF down | DEF + MDEF up |
| Blind | HIT + crit up |
| Slow / Root | Move speed up |
| Stun / Freeze / Fear / Silence | 2 s CC immunity |

A Miko is strongest against heavy debuff fights (curse, poison, CC bosses) — a different job from the Arch Druid
(raw healing and HOT) and Gut Shaman (offensive buffs). Other healers cleanse; only the Miko converts.

## Skill tree

2nd job — Miko (10)
1. **Harae Sweep** (Active) — sweep of the gohei wand: cleanse one ally, convert its debuffs.
2. **Kagura Purification Dance** (Active) — short dance: party heal in range + cleanse one debuff each (converted).
3. **Suzu Bell Blessing** (Active) — ASPD + Flee on one ally (kept).
4. **Ofuda Ward Shot** (Active) — replaces Evil Warding Arrow: thrown purifying talisman, holy damage + knockback 3.
5. **Cleansing Rain** (Active) — long CD: cleanse every debuff on the whole party, all converted.
6. **Holy Ward** (Passive) — less Shadow/Undead damage (kept).
7. **Priestess Grace** (Passive) — +heal power (kept).
8. **Blessing Craft** (Passive, signature) — converted blessings last longer and are stronger.
9. **Purify** (Passive) — every 5 s may cleanse Poison near the Miko (also converted).
10. **Shrine Path** (Passive) — faster while walking through any ally ground zone (was Sacred Steps; no longer tied to
    the removed Boundary Ward).

Removed: Divine Protection (low-HP defence, overlaps Juggernaut/Taiga).

3rd job — High Oracle Priestess (5)
11. **Divine Miracle Resurrection** (Ultimate Active) — the game's only full-party mass resurrection (Druid's Mass
    Resurrection moves into World Tree only).
12. **Kotodama Sacred Song** (Ultimate Active) — party ATK/MATK (kept).
13. **Sun Pillar** (Ultimate Active) — was Amaterasu's Light (no deity name): pillar of light damages enemies, heals
    allies.
14. **Divine Grace** (Ultimate Passive) — chance a heal's cooldown resets (kept).
15. **Oracle's Vision** (Ultimate Passive) — party sees boss HP (kept).
