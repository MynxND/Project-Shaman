# Skill Thai names (readable set, 2026-10-11)

The `thaiName` maps in `skills-thailand.ts`, `skills-indonesia.ts` and `skills-russia.ts` hold the "Thai name" column.
History: a Pali-Sanskrit set was approved and applied earlier on 2026-10-11, then the user found it too hard to read
("ศัพท์เฉพาะตัวเกินไป"); it is kept in the last column for reference only. Rules for the readable set:
- Everyday Thai a player understands at a glance; Pali-Sanskrit only where the word is common (มหา, โลหิต, วิญญาณ,
  อมตะ, ปราการ, อภิญญา, คาถา, มนตร์).
- 2–4 words, says what the skill does or looks like; mastery passives start with "ชำนาญ".
- Nation flavour from the theme itself (พราย, สายสิญจน์, พยนต์, กริช, มนต์ดำ, หมาป่า, ไทกา), not from rare roots.
