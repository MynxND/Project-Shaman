You are a senior 2D MMORPG environment artist, pixel-art technical artist, level designer, and game engine programmer.

I have attached a visual reference showing four detailed Shaman-themed environments:

1. Shaman Village (หมู่บ้านหมอผี)
2. Sacred Forest (ป่าศักดิ์สิทธิ์)
3. Cursed Swamp (หนองคำสาป)
4. Ancient Ruins (โบราณสถาน)

**Your primary objective is to recreate the visual appearance, atmosphere, environmental detail, terrain quality, and map composition of the attached reference as closely as possible inside my existing playable game.**

This is NOT a request for a generic fantasy map.

The attached image is the visual source of truth. Study it carefully before implementing anything.

## 1. Inspect the Existing Project

Before making changes:

- Identify the current rendering engine and map system.
- Inspect all map data, tilesets, environmental assets, collision layers, entity placement, and camera logic.
- Identify the tile size, world scale, sprite resolution, and rendering order.
- Locate the existing four maps and their transitions.
- Determine which assets can be reused and which must be replaced.
- Preserve existing gameplay systems, monsters, NPCs, quests, interactions, and comments.

Do not rewrite the entire game unnecessarily.

## 2. Visual Style — Match the Reference

Target art direction:

- Premium 2D pixel-art dark fantasy MMORPG.
- Southeast Asian shamanic folklore atmosphere.
- Dense, mysterious forests and ancient ritual sites.
- Highly detailed hand-painted pixel-art textures.
- Rich natural materials, aged wood, mossy stone, mud, roots, and weathered ritual objects.
- Warm orange torchlight contrasting with dark green and blue environments.
- Subtle fog, atmospheric depth, and carefully controlled shadows.
- Cohesive pixel density, camera angle, character scale, and environmental lighting.

Avoid:
- Japanese temples, torii gates, pagodas, or Japanese shrine architecture.
- Generic medieval European fantasy architecture.
- Flat green grass with repetitive dot patterns.
- Uniform brown rectangular dirt paths.
- Large empty spaces with randomly scattered objects.
- Oversized decorations that obstruct player movement.
- Blurry upscaling or inconsistent pixel-art styles.
