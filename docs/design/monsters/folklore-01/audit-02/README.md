# ตรวจแอนิเมชันมอนสเตอร์ รอบ02

ตรวจภาพเรียงเวลาครบ40ตัว ×8ทิศ ×3ท่า =960คลิป จาก atlas ที่ใช้งานจริง แผ่นภาพในโฟลเดอร์นี้เป็นหลักฐานก่อนแก้; `after/` แสดง9ตัวหลังแก้ลำดับ ทดสอบการเล่นใน browser เป็นตัวอย่างแยกจากการตรวจภาพครบทุกเฟรม ไม่อ้างว่าได้เล่นสดครบทุกคลิป

## สิ่งที่แก้จากเฟรมเดิม

9ตัว: Dalgyal Gwishin, Gumiho, Rusalka, Nokken, Nisse, Tilberi, Draugen, Draugur, Gashadokuro. เจ็ดตัวเติม neutral recovery; Draugur/Gashadokuro ใช้ neutral → windup → strike → neutral. จำนวน4เฟรมครบ8ทิศ ใช้ indices ของภาพเดิม ไม่มีการวาด limb ใหม่. เพิ่ม attackImpactFrame ให้จังหวะโดนมาจาก pose ฟาด ไม่เดาจากจำนวนเฟรมอีกต่อไป. Rusalkaยัง impact1; ที่เหลือ impact2

แก้ preview: หยุดแล้วค้างเฟรมปัจจุบัน, เล่นต่อจากเฟรมนั้น, เล่นท่านี้ใหม่เริ่ม0แม้หยุดอยู่, เริ่มเวลาเมื่อภาพโหลดแล้ว, ความเร็ว0.25×/0.5× และสลับก่อน–หลังได้ พร้อมตาราง40ตัว ไม่รวมผลทดสอบทางเทคนิคเป็นการอนุมัติภาพ

## ภาพที่ยังต้องทำต่อ

22ตัวต้องภาพเดินที่เห็น contact ซ้าย–ขวาและ support leg ชัดขึ้น; การเปลี่ยนดัชนีไม่สร้างขาที่ขาด หูหลีจิง/มาเรมีท่าตาย2เฟรม ต้องภาพยุบ/สลายเพิ่ม ไม่แก้ด้วยการเล่นซ้ำเพื่ออ้างว่ามี4pose. อีก18ตัวเป็นการลอย/บิน/กระโดด/ขดตัว ไม่บังคับเป็นการเดิน แต่ยังระบุว่าเคลื่อนไหวน้อย ไม่ใช่ผ่านขั้นสุดท้าย

สร้าง walk-only candidates3ชุด (เปรต ปอบ โครงกระดูกยักษ์) ด้วย ImageGenตามที่ผู้ใช้อนุญาต เก็บ PNG/คำสั่งครบ ยังไม่แทนเกม: การสลับเท้ารองรับ/สัดส่วนยังไม่ยืนยันครบทุกมุม และปอบมีเฟรมยกแขนเหมือนโจมตี ไม่สั่งเจนจำนวนมากต่อบนรูปแบบที่ยังไม่ผ่าน. ภาพเดิมใน runtimeยังคงอยู่พร้อมป้ายต้องแก้ภาพ ขอบเขตส่งมอบรอบนี้คือ auditครบและแก้ลำดับที่ทำได้ ไม่อ้างว่าแก้ภาพเดินทั้ง22ตัวเสร็จ

## การทำซ้ำ

`pack.py` → `apply-audit.mjs` → `publish.mjs` → shared build → `test.mjs`. ก่อนแก้ใช้ immutable `before-drafts.json`; scriptแก้ลำดับทำซ้ำได้โดยไม่เติม recoveryซ้ำ. `audit.py --after` สร้างหลักฐานหลังแก้9ตัวเท่านั้น. PNG runtimeเดิมทั้งหมดต้องมีhashเดิมในรอบนี้. กฎcollision/spawn/NPC/portalไม่เปลี่ยน

## ผลตรวจระบบ

`qa.py` ผ่านทุก atlas/action/direction/source hash; runtime PNGทั้ง40ตรงHEADเดิมแบบbyte-exact. ทดสอบแก้ลำดับซ้ำแล้วข้อมูลไม่เปลี่ยน; server hitทั้ง9เกิดที่deadlineที่ระบุ ไม่เกิดก่อน. Shared regression suite, typecheck และ production buildผ่าน. Browserตรวจ pause/replay/before-after, ตาราง41แถวรวมheader, desktopและmobile390×844, layoutแนวนอน844×390ไม่ล้นแนวนอน. รูป desktop.png/mobile.pngแยกจากการอนุมัติภาพ. ยังไม่อ้างทดสอบการเล่นสดครบ960คลิปหรืออนุมัติ gaitใหม่
